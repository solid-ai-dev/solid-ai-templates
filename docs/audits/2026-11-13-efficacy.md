# Efficacy benchmark — 2026-11-13

We asked an AI to build the same small web app 15 times with each approach to giving it
our templates, and 15 times with no rules file at all (`none`). Each radar compares one
approach with `none`.

![Radar per approach](2026-11-13-efficacy-radar-dark.svg#gh-dark-mode-only)
![Radar per approach](2026-11-13-efficacy-radar-light.svg#gh-light-mode-only)

How to read it: the dashed ring is `none`. A point outside the ring means the approach
did better on that axis, inside it means worse. Each axis groups several measurements;
the appendix lists them.

## Each approach

Each verdict looks only at the measures chosen before the run to decide it: the hidden
tests, the security and data-protection checks, and the AI judge's scores for design,
readability, maintainability, security and data protection. One of them clearly worse
makes the verdict worse, whatever the rest gained.

### `lazyskills`

The same map, each template loaded as a skill when that work starts (22 lines).

- Better than no rules file at: security, data protection, design, maintainability and
  the tests it wrote.
- Worse at: reliability (1 of 15 runs passed clearly fewer of the hidden tests, 1 other
  would not start after a clean install); cost and time (about $7.06 a run, against
  $4.29 with no rules file).

**Verdict: better**, on the AI judge's security score, with none of the deciding
measures worse.

### `reference`

A short file that points the AI to the templates, which it reads itself (19 lines).

- Better than no rules file at: security, data protection, design, maintainability and
  the tests it wrote.
- Worse at: cost and time (about $7.21 a run, against $4.29 with no rules file).
- Noted, though reliability was not clearly worse overall: 1 of 15 runs passed clearly
  fewer of the hidden tests, 2 others would not start after a clean install.

**Verdict: better**, on the AI judge's security score and the security checks, with none
of the deciding measures worse.

### `lazyref`

## The questions this round asked

- Does a template read when the work touches its topics do as well as the same template
  read before the work starts? **Not settled: the runs could not tell either way.**
  - `lazyref` read every template of its map before its first write in 5 of the 15
trials that wrote. Those trials measured reading up front, not on demand.
- Does loading a template as a skill do as well as reading it as a file, at the same
  moments? **Not settled: the runs could not tell either way.**
- Do templates loaded whole as skills, at a named moment, do as well as task skills
  offered by description? **Not settled: the runs could not tell either way.**

## How sure we are

- Each approach ran 15 times on one small web app, built by one AI model,
  `claude-sonnet-5`.
- Automatic tests and tools measured most of it. Another AI, `gpt-6-astra`, read the
  code and scored its design, security and tests.
- A difference counts only when it shows clearly across the runs. Small or mixed
  differences count as none.
- 4 runs were stopped part-way, for example by a usage limit, and run again from the
  start. Only complete runs count.
- 135 runs were scored in all.
